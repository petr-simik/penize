# Přehled příjmů a výdajů

Měsíční rozpočet v prohlížeči: plán a skutečnost, platby k odškrtnutí,
balíčky placené po částech, kategorie a společné nákupy.

**https://petr-simik.github.io/penize/**

Tenhle repozitář obsahuje jen kód aplikace, žádná data. Každý, kdo ji
otevře, začíná s prázdným rozpočtem, který se ukládá jen v jeho zařízení.
Volitelně se dá synchronizovat přes vlastní soukromý GitHub repozitář
(Nastavení → Synchronizace).

Na iPhonu: otevři odkaz v Safari → Sdílet → Přidat na plochu.
Na Androidu: v Chromu nabídka ⋮ → Přidat na plochu / Nainstalovat.
